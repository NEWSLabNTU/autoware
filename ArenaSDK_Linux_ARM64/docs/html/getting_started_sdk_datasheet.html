Arena SDK Datasheet¶

LUCID Arena SDK for Windows¶

Data interface Gigabit Ethernet (1000 Mbit/s): 1, 2.5, 5, 10 GigE
Operating system Windows 10 (32-bit and 64-bit); Windows 11 (64-bit)
Compiler Visual Studio 2015 and Visual Studio 2019 project files included
Programming languages C++, C, C#, and Python
Supported standards GenICam 3, GenTL 1.5, SFNC 2.3, GigE Vision 2.0
Supported cameras All LUCID GigE Vision cameras

LUCID Arena SDK for Linux¶

Data interface Gigabit Ethernet (1000 Mbit/s)
Operating system (x86 and ARM) Ubuntu 20.04 / 22.04 (64-bit)
Compiler G++ 5 or higher
Programming languages C++ and C
Supported standards GenICam 3, GenTL 1.5, SFNC 2.3, GigE Vision 2.0
Supported cameras All LUCID GigE Vision cameras

Minimum Requirements (x86 or x64 platforms)¶

CPU Intel Core i3-4340 CPU @ 3.60 GHz (Haswell)
Memory 4 GB
Network Ethernet adapter required (dedicated Ethernet adapter recommended)

Recommended Requirements¶

Single camera system

CPU Intel Core i5 from Skylake series or higher
Memory 8 GB or higher
Network Dedicated Intel Ethernet adapter

Multi-camera system

CPU Intel Core i7 from Skylake series or higher
Memory 16 GB or higher
Network Dedicated Intel Ethernet adapter(s)

Documentation API Reference for C++, C, C#, and Python

LUCID Software¶

ArenaConfig A utility for configuring Ethernet adapters and cameras.
ArenaView Camera configuration and streaming software for Windows.
IPConfigUtility A utility for camera IP configuration.
LUCIDDriverInstaller A utility to install and uninstall filter drivers for Windows.
LUCIDFirmwareUpdater A utility to update camera firmware for Windows.
