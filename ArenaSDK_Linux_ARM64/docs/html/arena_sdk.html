Arena SDK Manual¶

Arena SDK Datasheet¶

LUCID Arena SDK for Windows¶

Data interface Gigabit Ethernet (1000 Mbit/s): 1, 2.5, 5, 10 GigE
Operating system Windows 10 (32-bit and 64-bit); Windows 11 (64-bit)
Compiler Visual Studio 2015 and Visual Studio 2019 project files included
Programming languages C++, C, C#, and Python
Supported standards GenICam 3, GenTL 1.5, SFNC 2.3, GigE Vision 2.0
Supported cameras All LUCID GigE Vision cameras

LUCID Arena SDK for Linux¶

Data interface Gigabit Ethernet (1000 Mbit/s)
Operating system (x86 and ARM) Ubuntu 20.04 / 22.04 (64-bit)
Compiler G++ 5 or higher
Programming languages C++ and C
Supported standards GenICam 3, GenTL 1.5, SFNC 2.3, GigE Vision 2.0
Supported cameras All LUCID GigE Vision cameras

Minimum Requirements (x86 or x64 platforms)¶

CPU Intel Core i3-4340 CPU @ 3.60 GHz (Haswell)
Memory 4 GB
Network Ethernet adapter required (dedicated Ethernet adapter recommended)

Recommended Requirements¶

Single camera system

CPU Intel Core i5 from Skylake series or higher
Memory 8 GB or higher
Network Dedicated Intel Ethernet adapter

Multi-camera system

CPU Intel Core i7 from Skylake series or higher
Memory 16 GB or higher
Network Dedicated Intel Ethernet adapter(s)

Code Samples¶

Extensive code samples are available for each supported programming language that illustrate how to manage cameras in different image acquisition scenarios. These code samples are added by the ArenaSDK installer when the “Developer” profile is selected during installation. The default location for the code samples is shown below.

  • C:\ProgramData\Lucid Vision Labs\Examples

The recommended project properties files for Visual Studio (cpp_examples.props and cpp_ui_examples.props) are available in this folder as well.

Distributing Arena SDK Programs for Windows¶

This section describes the requirements for distributing your Arena SDK-based program to another Windows system.

Microsoft Visual C++ Redistributables¶

The Microsoft Visual C++ Redistributables should be installed first. The redistributable to be installed depends on the architecture of the program. For example, a 32-bit program will only need the 32-bit redistributables.

Microsoft Visual C++ 2015 Redistributable:

  • 32-bit (x86): 14.0.24215
  • 64-bit (x64): 14.0.24215
  • https://www.microsoft.com/en-us/download/details.aspx?id=53840

For further information on the Microsoft Visual C++ Redistributables, see Microsoft’s article titled Redistributing Visual C++ Files:

  • For Visual Studio 2015: https://learn.microsoft.com/en-us/cpp/windows/redistributing-visual-cpp-files?view=msvc-140

Microsoft .NET Framework¶

Microsoft .NET Framework version 4.5.2 or later is required for programs using the ArenaNET libraries. The Microsoft .NET Framework offline installer for version 4.5.2 can be found at this link: https://www.microsoft.com/en-ca/download/details.aspx?id=42642

Arena SDK¶

The following files must be placed in the same directory as your executable. This document describes distributing release versions of the Arena SDK libraries and its required dependencies. The debug libraries included with Arena SDK have an additional d after the library name (e.x. Distributing Arena SDK Programs for Linux¶

This section describes the requirements for distributing your Arena SDK-based program to another Linux system.

x64 Linux¶

The following folders are found in the Arena SDK tarball for x64 Linux. Ensure that their contents are available to your application.

  • /lib64
  • /GenICam/library/lib/Linux64_x64
  • /ffmpeg

ARM Linux¶

The following folders are found in the Arena SDK tarball for ARM Linux. Ensure that their contents are available to your application.

  • /lib
  • /Linux64_ARM
  • /ffmpeg
